# Terra-Project-1

First Terra Project.

## Dungeon Survivor

A 2D dungeon survival game built with Python and Pygame. Explore a dungeon, avoid enemies, collect coins, and survive long enough to escape.

## Run the game

Install the dependencies, activate the project's virtual environment, and start the game:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python3 main.py
```

In VS Code, open this folder and select `.venv/bin/python` as the Python interpreter if it is not selected automatically.
